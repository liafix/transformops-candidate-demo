# Limitations — Foundation Batch

This repository is intentionally incomplete after M0 + M1.

Not yet available:

- executable transformation rules;
- executable validation rules;
- lifecycle transition enforcement;
- transactional validation orchestration;
- REST/API contract;
- data-heavy reviewer UI;
- automated rule/service/API test coverage;
- browser smoke tests;
- preview or production deployment.

The checked-in migration SQL and seed code must be executed in a real PostgreSQL environment before being described as verified.
